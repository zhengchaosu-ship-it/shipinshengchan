# 发布管理 V0.1 界面约束

延续现有寻帧样式，不改全局CSS。截图核对最终有效CSS覆盖为：底色 #edf2f4、正文 #173246、主动作 #087683、边框 #d5e0e5、面板 #ffffff、标题区 #102c40；Segoe UI / Microsoft YaHei 本地系统字体。工作区入口与搜索模式分离，避免走进合成分支。认证后使用账号/计划/任务三个页签，管理员才显示员工/同步页签。

计划页先明确STARTUP/COMMERCE，左侧参数、右侧实时表格，核心关系是「日首发时间 + 数量 + 间隔 → 时间槽 → 本地任务」。确认按钮和测试警告同屏；稳定ID作为辅助字段而不是视觉主标题。未知组身份不提供绑定选项。账号页分起号/带货两段，员工编辑每类用多选，不限制组数量，不按名称自动分类型；同步成功提示只显示数量，未取得组ID用独立警告，避免长JSON占据视线。

实现前自检：不增加装饰性指标卡，不引入新字体、远程头像或动画；长ID放表格；禁用确认按钮必须同时显示原因；管理员角色来自服务器会话，不来自UI角色下拉；窄屏使用Streamlit原生响应式布局，不重写主工作台。

布局全部左对齐，布局关系：

```text
素材工作台 | 发布管理
我的账号 | 发布计划 | 发布任务 | [管理员：员工管理 / 同步]
参数（日期/时间/账号/成片） | 即时时间槽表
                            | 预览 / 确认创建 / 新计划
```

截图自检：保留既有寻帧标题区；真实账号表中的None显示为未取得字段，配套警告，不把默认组名冒充外键。表格长路径与任务字段可水平滚动；不新增全局CSS覆写或远程资源。最终视觉与最初读到的旧绿版CSS不同，是已有样式文件后半段蓝版覆盖的结果，不属于本轮重设计。

# 自动起号UI原型

原型面向按账号操作的员工，以固定五个时钟位置形成一条“明日安排”时间带；它承载业务排期而不是装饰编号。账号概况占上半屏，设置在独立面板。工程数据只在管理员预览中展开。

色彩：纸白#FFFFFF、背景蓝灰#EDF2F7、正文藏蓝#18334B、行动蓝#245AA8、正常青#14675B、需要处理赭黄#865400。字体使用本机Microsoft YaHei UI，正文16px，标题28px，行长约60字。左对齐；只在五个真实时间槽使用等宽排列，移动端垂直排列。

审阅调整：不采用一屏重复数字卡片；将五个发布时刻呈现为带状态的日程。当前粉丝在未知时显示“待获取”，不能用示例数字冒充账号实测值。样例素材和所有动作均标明演示，不连生产API，不上传资源，不持久化真实授权。

`prototype.html`为离线交互原型；员工预览/管理员预览仅切换演示视图，不是鉴权功能。正式UI接线必须复用既有8502会话、员工账号权限和服务端ADMIN校验。配置修改需要重新授权，不允许任意替换模板版本。

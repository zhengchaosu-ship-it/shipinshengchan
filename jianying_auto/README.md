# 剪映全自动合成流水线 - 交接文档

> 南宁大健康口播视频工作室，创业者苏政超专用。
> 本脚本直接生成剪映专业版草稿 JSON，无需打开剪映操作，运行后在剪映草稿列表即可看到成片。

---

## 一、环境

- Windows，Python 3.14+
- 依赖：`pip install -r requirements.txt`
  - `pyJianYingDraft>=0.3.0`（核心库，直接生成剪映草稿）
  - `faster-whisper>=1.0.0`（CPU int8 small 模型，中文语音转字幕）
  - `pymediainfo`（读视频时长）
  - `imageio-ffmpeg`（提取直播音频用）
- 剪映专业版 PC 版，草稿目录默认：
  `C:\Users\<用户>\AppData\Local\JianyingPro\User Data\Projects\com.lveditor.draft`
- Whisper 首次运行自动下载 small 模型（走 HF 镜像 `https://hf-mirror.com`）。

## 二、文件清单

| 文件 | 作用 |
|---|---|
| `jianying_auto.py` | 主脚本，全部流水线 |
| `config.json` | 素材路径配置（换电脑只改这个） |
| `jianying_source_folders.json` | 起号4类真实素材目录（网页与脚本共用） |
| `source_catalog.py` | 4类目录的递归只读扫描与格式白名单 |
| `combo_skeleton.json` | 复合片段骨架（当前未启用，保留） |
| `requirements.txt` | Python 依赖 |
| `README.md` | 本文档 |

运行方式：
```
python jianying_auto.py 坐诊|手法|流量手法|"引流+手法+坐诊+收尾"
```
不带参数默认坐诊。组合串用 `+` 连接，不带数字=随机选一段，带数字=指定递归自然排序后的第 N 个（如 `引流1+手法2`）。旧名称“流量”继续映射到“引流”。同一组合内同类随机项优先使用不同视频，只有素材数不足时才重复。

寻帧网页入口固定显示5个Slot，但只生成从片段1开始连续选择的1～5个有效片段；片段2～5的“无”不会传入本脚本或创建空时间线片段。单段网页任务使用一个带编号Token（如 `手法12`）调用本脚本，仍复用同一流水线。网页支持按同一Slot结构一次生成1～10条独立草稿，每条重新选材，并用“Slot类型+源文件路径”签名尽量避免本批次完整组合重复；批次记录位于 `runtime/batches/<batch_id>/batch_manifest.json`，每条另有 `video_XX.json`。草稿仍直接创建在剪映草稿根目录。

## 三、素材库配置

起号主素材只修改 `jianying_source_folders.json`，当前固定分类为引流、手法、坐诊、收尾；网页和脚本读取同一份配置。四类目录会递归扫描，但不会跟随链接离开配置目录；支持 `.mp4/.mov/.ts/.mkv/.avi/.flv/.m4v/.webm`。旧 `config.json` 中对应字段仅在这份独立配置缺失时作为兼容回退。

| 别名 | config 键 | 默认路径 | 说明 |
|---|---|---|---|
| 坐诊 | `lib1` | `E:\备份\精简` | 坐诊口播绿幕素材 |
| 手法 | `green_dir` | `E:\备份\起号手法\手法绿幕` | 手法演示绿幕素材 |
| 引流（兼容旧名“流量”） | `pull_dir` | `E:\备份\起号手法\引流话术` | 引流开头话术绿幕 |
| 收尾 | `shouwei_dir` | `E:\备份\起号手法\收尾` | 点赞收尾绿幕 |
| 背景 | `bg_dir` | `E:\备份\背景素材` | 随机背景图（jpg/png） |
| 扫光 | `sweep_dir` | `E:\备份\Y148-...\1.扫光消重素材` | 扫光消重视频 |
| 粒子 | `particle_dir` | `E:\备份\Y148-...\粒子消重背景` | 粒子消重视频 |
| 直播 | `live_dir` | `E:\备份\去重直播\...` | 直播切片（当前素材暂缺，自动跳过） |
| 贴纸索引 | `sticker_key_value` | `D:\JianyingPro Drafts\贴纸\key_value.json` | 贴纸草稿导出的素材索引 |
| 特效滤镜索引 | `effect_filter_kv` | `D:\JianyingPro Drafts\特效滤镜\key_value.json` | 特效滤镜草稿导出的索引 |

**贴纸/特效索引怎么来**：在剪映里建一个叫"贴纸"的草稿，把要用的贴纸全拖进去；再建一个叫"特效滤镜"的草稿，把要用的特效和滤镜拖进去。脚本会自动读这两个草稿目录下的 `key_value.json`（剪映生成的素材索引）。如果 config 里路径不对，脚本会自动从剪映草稿根目录下找"贴纸"/"特效滤镜"子目录。

## 四、流水线步骤（按执行顺序）

1. **选素材拼接**：按用户给的组合串，从对应素材库随机/指定选段，顺序拼接成主视频。所有拼接段都加绿幕色度抠像（边缘清除=6）。
2. **背景层**：从背景图库随机选一张，铺满整个时间线，垫在最底层。
3. **字幕识别**：用 faster-whisper 逐段转写，合并成 SRT，写入字幕轨道。敏感词按 `SENSITIVE_MAP` 替换（长词优先，再单字替换）。
4. **固定标题**：两个独立 text 轨道：
   - 标题-黄：榜楷体，字号17，黄色字+黑边，Y轴=725/960
   - 标题-白：榜楷体，字号15，白色字+红边，Y轴=550/960
   - 字间距3，行间距3
5. **字幕轨道**：榜楷体，字号14，黄色黑边样式，Y轴=-500/960（归一化坐标）。
6. **贴纸复合片段**：从贴纸草稿随机抽6个不同贴纸（不能重复），每个随机位置（±0.55）、随机放大3.5~6.0倍、随机旋转-180~180°；随后自动新建一个复合片段，统一设置混合模式为滤色、不透明度1%。复合片段内各贴纸保持100%不透明，不重复叠加透明度。
7. **特效3个**：从特效草稿随机抽3个，强度=0.01（即1%）。
8. **滤镜3个**：从滤镜草稿随机抽3个，强度=0.01。
9. **扫光3条轨道**：每条轨道用扫光素材随机拼接铺满全片，随机放大1.5~3.2倍、随机旋转，混合模式滤色，不透明度5%。
10. **粒子3条轨道**：每条轨道用粒子素材随机拼接铺满全片，随机放大1.5~3.2倍、随机旋转，混合模式滤色，不透明度1%，全部静音。
11. **直播8条轨道**（素材暂缺时自动跳过）：同一直播视频取8个不同时间切片，每条随机缩放1.0~2.2、随机位移±0.35、随机旋转，铺满画面，滤色1%，全静音。再随机抽3条分离音频到独立音轨，音量-46dB。
12. **轨道排序**：按层级重排（从顶到底）：直播8→粒子3→扫光3→滤镜3→特效3→贴纸6→标题(2条text)→字幕(text)→主视频→背景。
13. **补全 draft_meta_info.json**：pyJianYingDraft 库默认写空 meta，导致剪映草稿列表看不到草稿。脚本在 save 后手动补 `draft_name`/`draft_fold_path`/`draft_root_path`/`tm_duration`/`tm_draft_create`/`tm_draft_modified`。

## 五、轨道层级（最终从顶到底）

```
直播-1 ~ 直播-8      （滤色1%，静音，8条）
粒子-1 ~ 粒子-3      （滤色1%，静音，3条）
扫光-1 ~ 扫光-3      （滤色5%，3条）
滤镜-1 ~ 滤镜-3      （强度1%，3条）
特效-1 ~ 特效-3      （强度1%，3条）
贴纸复合片段          （内含6个贴纸，整体滤色1%，1条）
标题-黄 (text)       （Y=725，字号17）
标题-白 (text)       （Y=550，字号15）
字幕 (text)          （Y=-500，字号14）
主视频 (video)       （拼接的绿幕口播）
背景 (video/photo)   （随机背景图）
```

## 六、敏感词替换表

在脚本 `SENSITIVE_MAP` 字典里。原则：医疗/大健康敏感词用形近字替换，避免平台审核。替换顺序：先替换长词（如"肺结节"），再替换单字（如"肺"），用占位符防止二次替换。当前表约80个词，运行时如需新增直接往字典里加。

## 七、已知限制 / 手动步骤

1. **贴纸复合片段**：已按剪映11.5实际草稿结构接入虚拟视频素材、内嵌子草稿和外层复合引用。`config.json` 的 `sticker_combination` 默认为 `true`；设为 `false` 可回退为6条独立贴纸轨道。
2. **直播蒙版**：用户曾要求给8条直播轨道加线性蒙版/图形蒙版，pyJianYingDraft 的蒙版 API 在新版剪映上显示异常，用户已决定手动加蒙版。
3. **直播素材**：当前 `live_sample.mp4` 暂缺，脚本自动跳过直播层。素材准备好后放到 `live_dir` 下命名为 `live_sample.mp4` 即可恢复，无需改代码。
4. **字幕样式**：如果字幕字体没显示，关掉草稿重开一次剪映即可（剪映首次加载字体缓存）。

## 九、注意事项

- 时间单位：微秒，1秒=1,000,000。
- 归一化坐标：X/Y 范围 -1~1，0为中心，-1为左/上，1为右/下。
- 不透明度：脚本里 0.01 = 1%，0.05 = 5%。
- 强度：特效/滤镜强度 0.01 = 1%。
- 草稿命名：按类型前缀递增，如"手法1"、"流量手法3"、"坐诊2"、"组合5"。
- 运行多条：用 `for` 循环串行跑，不要并行（Whisper模型加载和文件IO会冲突）。
